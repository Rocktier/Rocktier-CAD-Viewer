# Rocktier CAD Viewer — 实施计划

## 定位（与 rocktier.com 家族品牌保持一致）

Rocktier 家族第四款产品，继承官网三大品牌承诺：
- **Fast is a feature**：秒开大图，GPU 渲染 60fps 缩放平移，安装包 ~15MB
- **Private by design**：完全离线运行，零上传、零追踪、零分析（对齐官网 "no tracking, no analytics"）
- **Rock solid**：单一只做好一件事——看图，不编辑
- 官网产品卡风格文案："Fast, private, no internet needed. Cross-platform Windows + macOS."
- **双语 UI（中文/English）**，语言偏好本地保存；**明暗主题**，主题偏好本地保存（对齐官网隐私声明）
- About 对话框包含家族品牌 "Create with grit." 与 hello@rocktier.studio 反馈入口
- 实施第一步会抓取官网 CSS 提取确切的配色/字体，应用到 UI

## 技术选型（已确认）

**Tauri 2 + Rust + TypeScript + WebGL，应用以 GPL-3.0 开源**

| 层 | 方案 |
|---|---|
| 外壳 | Tauri 2（Windows 用 WebView2，macOS 用 WKWebView，体积小启动快） |
| DXF 解析 | Rust `dxf` crate（MIT/Apache，纯 Rust） |
| DWG 解析 | LibreDWG 的 `dwg2dxf` 以 Tauri sidecar 捆绑，后台转 DXF（GPL，因此整个应用 GPL-3.0 开源） |
| 渲染 | Rust 侧把实体离散化为顶点缓冲（位置+颜色），前端 WebGL 画 hairline 线段（`gl.LINES` + per-vertex color）——专业看图软件的标准高速画法，百万线段无压力 |
| 前端 | Vite + TypeScript + Svelte（保持轻量），自研 WebGL 相机/批次/拾取模块 |
| 导出 | PNG：WebGL 离屏渲染；PDF：Rust 侧 `pdf-writer` 生成矢量线稿 |

## v1 功能范围（已确认：看图 + 测量 + 打印导出）

- **打开**：文件对话框 + 拖拽入窗 + 最近文件（仅本地记录）；DWG 后台转换带进度提示
- **看图**：滚轮缩放（光标为中心）、中/右键平移、缩放范围(Zoom Extents)、缩放窗口
- **图层**：图层列表、显隐开关、颜色色块
- **空间**：模型空间 + 图纸空间布局标签页
- **实体覆盖 v1**：LINE / CIRCLE / ARC / LWPOLYLINE / POLYLINE / ELLIPSE / SPLINE（离散化）/ TEXT / MTEXT（基础，内置线划字体）/ INSERT（块引用，含嵌套）/ HATCH（实心+基础图案）/ POINT / SOLID / DIMENSION（按预定义几何绘制）
- **测量**：距离测量，带基本对象捕捉（端点/中点/圆心/交点），状态栏实时坐标
- **导出/打印**：导出 PNG（当前视图或全图，2x 分辨率）、导出矢量 PDF（适页面、可选单色黑白）
- **外壳细节**：明暗主题切换、中英文切换、关于对话框、无网络依赖

## 项目结构

```
Rocktier CAD Viewer/
├── src-tauri/src/
│   ├── dxf/        # DXF 解析
│   ├── dwg/        # dwg2dxf sidecar 调用与进度
│   ├── model/      # 统一图形数据模型（实体/图层/块/布局）
│   ├── tess/       # 实体 → 顶点缓冲离散化（含线划文字）
│   ├── export/     # PDF 矢量导出
│   └── commands/   # Tauri IPC：open/scene/export 等
├── src/            # 前端：renderer/(相机、批次、拾取) ui/(工具栏、图层面板、标签页、状态栏) i18n/ theme/
├── binaries/       # dwg2dxf sidecar 占位（per-platform）
├── fixtures/       # 测试用 DXF 样例（脚本生成）+ 真实图纸测试
├── .github/workflows/build.yml   # 双平台 CI 构建 + GitHub Releases 发布
├── LICENSE (GPL-3.0)、README（双语、品牌语气）、third-party notices
```

## 实施里程碑（顺序执行，每步可运行验证）

1. **M1 渲染骨架**：Tauri 脚手架 + DXF 解析 + WebGL 线段渲染 + 缩放/平移/适应窗口。用脚本生成的 DXF 样例验证。
2. **M2 完整看图**：图层面板、模型/布局标签、块与文本/填充/标注实体覆盖、颜色与线型、明暗主题 + 中英文切换。
3. **M3 DWG 支持**：本机安装 LibreDWG（macOS brew / Windows vcpkg），sidecar 集成 + 转换进度 UI + 转换错误处理。
4. **M4 测量与导出**：捕捉 + 测距、坐标读数、PNG 导出、矢量 PDF 导出。
5. **M5 产品化**：应用图标（Rocktier 风格）、关于对话框、最近文件、README、GPL 许可与第三方声明、CI 双平台打包（macOS dmg 通用二进制 + Windows NSIS 安装包/便携版）。
6. **M6 验收**：真实大图（100MB 级 DXF）性能调优与实测，对照官网品牌逐项核对（离线、双语、主题、体积），产出 v1.0 可发布版本。

## 需要说明的两点

- **开源义务**：LibreDWG 是 GPL-3.0，整个应用需以 GPL-3.0 在 GitHub 公开源码（已获你确认）。`dxf` crate 为 MIT/Apache 无冲突。
- **签名**：macOS 不签名时用户需右键打开（Gatekeeper）；Windows SmartScreen 类似。签名证书（Apple $99/年）可后续再加，不影响 v1 发布到 GitHub Releases。
